# Sara Abad Media Page

Condensed one-page site inspired by clean personal-media layouts, with Sara's photo front-and-center.

## Run locally

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Open: <http://127.0.0.1:4173/index.html>

## Required hero image

Save the provided photo as `sara-photo.jpg` in the project root.
